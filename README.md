# lab-git-pushmina
Лабораторная работа по Git
## О проекте

   Учебный проект по дисциплине «Интернет-программирование».
   Создан для освоения системы контроля версий Git.
 ## Технологии

   - HTML5
   - CSS3
   - JavaScript
   - Git
 ## Установка

   1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/<username>/lab-git-<фамилия>.git
   ```
   2. Перейти в папку проекта:
   ```bash
   cd lab-git-<фамилия>
   ```
   3. Открыть файл `index.html` в браузере.
